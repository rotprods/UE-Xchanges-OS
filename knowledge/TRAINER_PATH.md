# Trainer Career Engine

## Target

Move from high-value participant/youth-worker activity to paid international trainer/facilitator work with verifiable non-formal education practice.

## Stages

T0 Programme literacy -> T1 Contributor -> T2 Assistant facilitator/co-facilitator -> T3 Qualifying full-time trainer activities #1–#3 -> T4 TOY-ready -> T5 Paid calls.

For each potential TOY reference verify: international/intercultural group; youth-work field; >=3 days; non-formal learning; full-time trainer responsibility for educational goals; reference person able to validate.

Isolated workshops can build skill but do not by themselves satisfy TOY reference criteria.

## TOY-ready assets

3 validated qualifying references; trainer CV; clear competence/topic positioning; methods portfolio; feedback/testimonials; working-English evidence; session designs/evaluation outputs.

## Positioning wedge

Do not position as "trainer of everything". Build 2–4 evidence-backed wedges. Candidate wedges to validate from private evidence: AI/digital literacy and agentic workflows; creative communication/storytelling/content; entrepreneurship/marketing; filmmaking/visual communication; digital facilitation.

## Paid calls

Monitor SALTO Calls for Trainers + direct organiser calls. Parse fee separately from EU travel/subsistence grant lines; rates/working conditions vary by organiser.
