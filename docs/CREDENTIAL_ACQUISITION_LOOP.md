# Credential Acquisition Loop — Youth Work → Trainer Path

## Objective

When a high-value opportunity is blocked by missing youth-work context, do not fabricate the credential and do not discard the strategic direction. Create legitimate evidence by doing useful youth work.

## Credential ladder

| Level | Meaning | Example evidence |
|---|---|---|
| L0 | Self-description only | profile statement |
| L1 | Verified affiliation/collaboration | youth organisation/service confirmation |
| L2 | Delivered youth activity | agenda + material + delivery proof + safe participant metadata |
| L3 | External reference / repeated practice | organiser reference, feedback, repeated activity |
| L4 | TOY-qualifying trainer reference | international youth-work training >=3 days as full-time trainer responsible for educational goals, NFE, validated reference |

Never collapse these levels.

## Mandatory graph

```text
CREDENTIAL_GAP_IDENTIFIED
 -> OUTREACH_PREPARED
 -> HUMAN_REVIEW
 -> COLLABORATION_CONFIRMED
 -> ACTIVITY_DESIGNED
 -> ACTIVITY_DELIVERED
 -> EVIDENCE_PACK_CAPTURED
 -> EXTERNAL_REFERENCE_CAPTURED?
 -> PROFILE_GATE_REEVALUATED
```

A proposal or draft email does not move the profile to PASS.

## Fast activity pattern

A useful first activity can combine existing professional strengths with a genuine youth-learning objective. Example theme:

**AI creative literacy: detect manipulation and create responsibly**

Suggested 90–120 minute non-formal structure:

1. check-in / experience mapping;
2. small-group challenge: real vs edited vs generated media;
3. source and evidence-checking exercise;
4. participant-created visual/storytelling task;
5. ethics/safeguarding canvas;
6. transfer to participants' own online contexts;
7. reflection + feedback.

The workshop should be adapted to the organisation, age group, accessibility needs and safeguarding requirements.

## Minimum L2 evidence pack

- organisation / service;
- date and duration;
- role actually performed;
- participant group described at safe aggregate level;
- learning objectives;
- agenda and NFE methods;
- activity materials;
- delivery confirmation;
- anonymised outputs only where appropriate;
- feedback/evaluation;
- organiser confirmation/reference when available;
- photo/video only where consent and safeguarding permit.

## Media contribution

Professional photo/video capability is a useful contribution to youth projects but remains subordinate to consent, privacy, safeguarding and the educational purpose. It is not evidence of youth-work practice unless it forms part of a real youth-work activity/role.

## Trainer progression

After genuine local youth-work practice exists:

`L2/L3 youth-work practice -> cofacilitation -> international training responsibility -> qualifying reference #1 -> #2 -> #3 -> TOY eligibility -> paid trainer calls`

Do not count participant roles, group leadership, isolated guest sessions or local short workshops as TOY references unless they independently satisfy the official TOY criteria.
