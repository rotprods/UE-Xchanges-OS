# UE-Xchanges-OS — Goals Projection

> This file is a recovery projection. Canonical goal authority is `../goal.md`; canonical agent contract is `../AGENTS.md`.

## Mission lock

Build and operate a persistent global mobility, paid-role and trainer/facilitator opportunity OS that discovers, verifies, prepares and executes every legitimate Spain-compatible opportunity while preserving truthful evidence, receipts, privacy and concurrency safety.

Policy: **APPLY EVERYTHING VIABLE**. Priority orders execution; it does not exclude viable routes.

## North stars

1. Coverage: `receipt-backed applications / live Spain-compatible opportunities`.
2. Economic: `verified net cash / verified work hour → verified net cash / committed hour → total verified net cash`.
3. Career: `expertise → youth-facing delivery → co-facilitation → references → paid international trainer/facilitator work`.
4. Reliability: zero known false submissions, duplicate submissions, fabricated claims, AI-policy bypasses, sensitive-attribute inventions, receipt guesses or conflicting lease writes.

## Current execution goals

### G1 — W9 conversion
Convert every viable live application to either:
- receipt-backed submission; or
- objective sourced terminal block.

Never count eligibility/query/preparation as submission.

### G2 — Human frontier compression
Reduce HUMAN READY backlog by surfacing only actions that genuinely require Roberto:
- login/MFA/CAPTCHA;
- identity/sensitive values;
- payments;
- applicant-owned final wording where required;
- irreversible submit until Submit capability is separately certified.

### G3 — Form Execution Gateway
Current achieved level: one-command local MCP Browser Stack with local inspect/prefill/validate and no Submit.
Next goal: certify **one** real external provider for authenticated INSPECT + supervised PREFILL only.

External Submit is a later independent goal and must require fresh Plan Identity, ApprovalToken, duplicate guard, persisted SubmissionAttempt, confirmation and durable receipt.

### G4 — RuntimeGraph autonomy
RuntimeGraph must ingest value-safe source events, maintain monotonic cursors/idempotency, self-heal derived projections and recompute Human/Agent/System frontiers without becoming a second source of domain truth.

### G5 — Recovery
Any zero-context agent must recover from durable state only: GitHub contracts + current checkpoint + Drive sessions/leases/event tail + fresh Gmail/official sources. Chat memory must be optional.
