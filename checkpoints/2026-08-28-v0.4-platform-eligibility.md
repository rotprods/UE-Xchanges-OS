# Checkpoint — 2026-08-28 — v0.4 Platform Eligibility

## Trigger

The live opportunity batch revealed that several extremely high-fit SALTO Training Calendar listings were being treated as application candidates while the private evidence graph did not establish actual youth-work/NFE involvement.

Fresh SALTO applicant guidance was promoted from background knowledge to a **source-level eligibility rule**: the European Training Calendar targets youth workers/trainers or people already involved in the youth-work context. Call-specific profiles may narrow this further.

## Deterministic change

- `ApplicantProfile.youth_work_context_verified: bool | None`
- `Opportunity.requires_youth_work_context: bool`
- SALTO calendar source policy sets the requirement automatically.
- Required context + private profile `null` => `UNKNOWN` / verification debt.
- Required context + true => PASS.
- Required context + false => FAIL.

The system does not infer true from adjacent expertise.
