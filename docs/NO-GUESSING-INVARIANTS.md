# No-Guessing Invariants

The system never guesses:

- whether a deadline moved;
- whether an authenticated submission occurred;
- whether a sensitive attribute applies;
- whether historical participation proves current youth-work activity;
- whether attendance proves trainer responsibility;
- whether silence means rejection;
- why an organiser rejected an application;
- whether lack of an AI prohibition means AI is allowed;
- whether an empty calendar means real availability;
- whether two similar project titles are the same call.

Each unresolved fact becomes an explicit verification/evidence node with provenance and a mandatory next route.
