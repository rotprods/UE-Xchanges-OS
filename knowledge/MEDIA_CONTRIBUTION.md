# Media Contribution Module — Photo / Video Value

## Purpose

Turn professional photography/videography into a credible project contribution without making the application sound transactional or like a content-production trip.

## Canonical value proposition

When relevant and permitted, the applicant can support the project and participating organisations with professional-quality photo/video documentation and a curated media pack at no charge, helping them document activities, communicate outcomes and disseminate the Erasmus+/ESC project after the mobility.

This is an **optional contribution module**. It is never injected blindly.

## Eligibility to use the module

Use only when all are true:

1. The project benefits from documentation, dissemination, storytelling or content.
2. The organiser's safeguarding/privacy/media rules permit it.
3. Participants can give appropriate informed consent.
4. The applicant can participate fully in the learning programme; media work must not replace attendance.
5. The promise is scoped realistically.

Do not use, or heavily constrain, when:

- minors/vulnerable participants create safeguarding concerns;
- a call explicitly restricts photography/recording;
- confidential or sensitive activities are involved;
- the role is primarily therapeutic/support work where cameras may reduce psychological safety;
- the contribution distracts from the stated participant/trainer role.

## Application positioning

Correct hierarchy:

`project motivation -> relevant experience -> contribution to learning/group -> optional media/dissemination contribution`

Not:

`I am a filmmaker, therefore select me.`

## Evidence required

The private evidence graph should contain:

- photography/videography professional experience;
- portfolio/work samples;
- examples of event/documentary/social content if available;
- editing/delivery capability;
- any relevant client/organisation references;
- consent/privacy workflow experience if applicable.

No unsupported quality claims.

## Deliverable menu

Choose with organisers after selection rather than over-promising in the application:

- curated edited photo selection;
- short vertical/landscape recap clips;
- participant/organisation portraits where consent allows;
- atmosphere/process documentation;
- final-project/output documentation;
- social/dissemination-ready assets;
- raw/edited archive handoff where agreed.

## Media Value Score 0–100

Score the opportunity, not the applicant:

- dissemination need: 0–25
- visual/storytelling richness: 0–20
- organiser likely reuse value: 0–20
- portfolio relevance: 0–15
- permission/safeguarding feasibility: 0–10
- operational feasibility without reducing participation: 0–10

A high Media Value may improve contribution fit; it never overrides eligibility or safeguarding.

## Consent guard

Before recording identifiable people:

- obtain organiser approval;
- follow project consent/release process;
- respect opt-out participants;
- follow rules for minors/vulnerable people;
- avoid sensitive private moments;
- agree where/how assets may be published.

The system should model these as requirements, not as a footnote.
