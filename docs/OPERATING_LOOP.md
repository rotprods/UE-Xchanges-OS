# Operating Loop

## Daily

Query Tier-0 sources + organisation watch; ingest only new/changed candidates; canonicalise/dedupe; verify eligibility-critical facts; hard-gate; rank; escalate A/A+ and high-value unknowns.

## High-priority call

Archive source/infopack; extract facts + selection language; identify organiser risks; map criteria to private evidence; list gaps; classify AI policy; generate dossier/strategy; human review; submit.

## Outcome loop

Record ACCEPTED/WAITLISTED/REJECTED/NO_RESPONSE/WITHDRAWN and exact feedback; update organisation/call priors; compare components; avoid overfitting one outcome; promote recurring relationships into the graph.

## Trainer loop

For every activity ask whether it can create a qualifying full-time trainer reference, whether educational responsibility can be expanded, who can validate it, which trainer competences it demonstrates, and whether a paid repeat relationship is plausible.
