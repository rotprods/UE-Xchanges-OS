# /define-goal — UE-Xchanges-OS

## North Star

Create a persistent EU mobility intelligence system that continuously finds the full relevant opportunity space, rejects ineligible/noisy opportunities early, converts infopacks and calls into structured evidence, and helps produce truthful high-conviction applications that materially improve acceptance rate — while deliberately building a path from participant/youth worker to paid international trainer/facilitator.

## Primary outcomes

1. Discovery dominance across official portals + high-yield organisation networks.
2. Zero wasted applications on known-ineligible calls.
3. Call-specific, evidence-backed, non-generic application dossiers.
4. Legitimate selection advantage through fit, contribution, reliability and multiplier effect.
5. Intentional accumulation of valid full-time international trainer references.
6. Persistent institutional memory: every opportunity, organisation, application, outcome and reference compounds the graph.

## Non-goals

Spam applications; fabricated credentials/fewer-opportunities claims; bypassing AI restrictions; blind form auto-submission; access-control bypassing; or embedding a general-purpose graph platform into this domain repo.

## Objective function

`NorthStar = AcceptedHighValueOpportunities / HumanApplicationHours`

Secondary: acceptance rate; paid trainer revenue/days; funded mobility days; median human minutes/application; qualified opportunities/week; missed deadline rate; eligibility error rate; policy violation rate; duplicate submission rate.

## Hard SLOs

- known-rule eligibility false-pass = 0
- duplicate submissions = 0
- fabricated external claims = 0
- known AI-policy violations = 0
- missed verified A/A+ deadlines = 0

## Strategic lanes

**A Participant** — Youth Exchanges, ESC, quality trainings to build network, programme literacy and proof.

**B Youth Worker / Facilitator** — professional-development roles where facilitation, media, digital, entrepreneurship, AI, communication or project skills create organiser value.

**C Paid Trainer / Expert** — SALTO Calls for Trainers and adjacent expert/facilitator calls; build qualifying trainer references deliberately until TOY criteria are met.

## Acceptance advantage thesis

The strongest legitimate edge is a better evidence-to-criteria match:

`criterion -> concrete proof -> project-specific contribution -> credible learning goal -> multiplier outcome`

## v1 operational definition

At least 5 primary sources ingest automatically; stable dedupe/freshness; tested hard gates; structured infopack extraction with provenance; private evidence retrieval; participant + trainer dossiers; graph outcome tracking; daily/weekly persistent opportunity briefs.
